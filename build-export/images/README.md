# Open Graph Images for SEO

## Required Images

The following Open Graph (OG) images are needed for the website to properly display rich previews when pages are shared on social media. Each image should be 1200×630 pixels for optimal display across platforms.

### Core Site Images

- `og-default.jpg` - Default image used when no specific OG image is available
- `og-home.jpg` - Home page image
- `og-manifesto.jpg` - Manifesto page image

### Perspectives Images

- `og-philosophical-foundations.jpg` - Image for the Philosophical Foundations page showing the intersection of Austrian Economics, Cypherpunk ideology, and Libertarian principles
- `og-bitcoin-vs-crypto.jpg` - Image contrasting Bitcoin with other cryptocurrencies
- `og-networked-revolution.jpg` - Image for Networked Revolution perspective
- `og-energy-alchemy.jpg` - Image for Energy Alchemy perspective
- `og-geopolitical-shield.jpg` - Image for Geopolitical Shield perspective
- `og-time-travelers-portfolio.jpg` - Image for Time Traveler's Portfolio perspective

## Image Guidelines

1. All images should maintain consistent branding with the site's color scheme
2. Text should be readable when the image is viewed at smaller sizes
3. Include the Bitcoin logo and/or symbol where appropriate
4. Ensure high contrast between text and background
5. Keep file sizes optimized (ideally under 200KB)
6. Use descriptive visuals that complement the page content

## Technical Specifications

- **Dimensions**: 1200×630 pixels (1.91:1 aspect ratio)
- **Format**: JPEG or PNG
- **Color Mode**: RGB
- **Resolution**: 72 DPI

## Social Media Platform Requirements

Different platforms may display the images differently:
- **Twitter**: Displays as a large card if properly sized
- **Facebook**: Shows the full image in feeds
- **LinkedIn**: Maintains aspect ratio but may crop slightly
- **Other platforms**: May vary in display but will use these images

## Example

```html
<meta property="og:image" content="https://storeofvalue.ch/images/og-bitcoin-vs-crypto.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
<meta property="og:image:alt" content="Bitcoin vs Other Cryptocurrencies - Understanding the key differences">
```
